# สถานการณ์น้ำท่วมกรุงเทพฯ และปริมณฑล (ก.ย. 2569)

หน้าสำรอง (mirror) ของ dashboard ข้อมูลน้ำท่วมเพื่อประโยชน์สาธารณะ
ข้อมูลจาก thaiwater.net (สสน.), สำนักการระบายน้ำ กทม., กรมอุตุนิยมวิทยา และข่าวที่อ้างหน่วยงาน
อัปเดตอัตโนมัติราวทุก 3 ชั่วโมง · ไม่ใช่ช่องทางทางการของหน่วยงานใด · อ่านข้อจำกัดการใช้งานท้ายหน้า
